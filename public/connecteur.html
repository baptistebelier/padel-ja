/RiseAndMove — Connecteur MCP

Claude connecté à vos applis /RAM.

Demandez à Claude le classement de votre dernier tournoi, le planning de votre semaine d'enseignant, la fiche d'un élève ou l'agenda de votre club : il lit vos données /RAM JA, /RAM Club et /RAM Coach avec votre compte /RAM.

Il lit /RAM JA, /RAM Club et /RAM Coach, et peut modifier /RAM Coach (groupes, élèves, messages, bilans en brouillon, niveaux) : Claude vous demande de confirmer chaque modification. Il ne voit et ne fait que ce que votre compte peut déjà voir et faire dans les applis.

Ajouter à Claude

Adresse du connecteur

https://ja.riseandmove.fr/mcp

Claude (claude.ai, appli ordinateur ou téléphone)

  1. Paramètres, puis Connecteurs, puis Ajouter un connecteur personnalisé.
  2. Nom : /RAM. Adresse : https://ja.riseandmove.fr/mcp.
  3. Touchez Se connecter : la page /RAM s'ouvre, connectez-vous avec votre compte /RAM puis touchez Autoriser.
  4. Dans une conversation, activez le connecteur /RAM dans le menu des outils.

Claude Code

claude mcp add --transport http ram https://ja.riseandmove.fr/mcp

Puis la commande /mcp dans Claude Code pour vous connecter avec votre compte /RAM.

Sur la page d'autorisation, cochez « Lecture seule » pour n'autoriser que la consultation.

Confidentialité

Votre compte garde la main

  • Connexion avec votre compte /RAM : votre mot de passe n'est jamais transmis à Claude.
  • Mêmes droits que dans les applis : les fiches élèves restent à l'équipe pédagogique, le suivi d'un élève à lui, ses parents et ses enseignants.
  • Pour couper l'accès : retirez le connecteur dans Claude, ou changez votre mot de passe /RAM.
